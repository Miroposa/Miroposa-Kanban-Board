# Kanban Board

Lokale Kanban-/Brainstorm-App (Manager + Boards + Flipcharts).

## Start

1. Doppelklick: `kanban-kit/Kanban Manager oeffnen.bat`
2. Oder Desktop-Verknüpfung **Kanban-Manager**

Manager: http://127.0.0.1:8760/manager.html

## Ordner

| Pfad | Inhalt |
|------|--------|
| `kanban-kit/` | Manager, Vorlage, Icons |
| `brainstorm/` | Janamathics-Board (Port 8765) |
| `boards/` | optionaler Boards-Ordner im Projekt |

Neue Boards landen standardmäßig unter `Downloads/<name>/`.
